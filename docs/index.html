GOOD TO KNOW

Questions, answered.

Do I need to know Python already?

The fundamentals track starts with the core ideas and guided Python examples. Basic coding familiarity helps, but you can begin as a curious beginner.

What do founding members get?

Founding seats are intended to include launch track access, the project-first path, and updates as the platform grows. Exact release timing and access details will be confirmed before live enrollment opens.

Is the ML Playground using an AI API?

No. The labs run entirely in your browser with JavaScript math and Canvas, with no API key or backend required.

Is the seat counter live?

While the campaign is in preview, the counter and activity examples are sample data. We will connect verified signups and a shared counter before accepting live registrations.
