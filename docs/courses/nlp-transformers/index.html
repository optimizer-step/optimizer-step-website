NLP & Transformers

Learn how machines read: tokens, embeddings, similarity and the attention mechanism behind transformers. Then build a text classifier and study the mistakes it makes.

  • NLP
  • Embeddings
  • Attention
  • Transformers
See the syllabus

What you'll learn

  1. Tokenization and text features

    Split text into tokens and turn words into numbers a model can use.

  2. Embeddings and semantic similarity

    Represent meaning as vectors and measure how close two pieces of text are.

  3. Attention and transformer intuition

    Understand how attention decides which words matter: the core idea behind transformers.

  4. Text classification and evaluation

    Build a classifier, evaluate it fairly, and learn from the examples it gets wrong.

Your project

Build a text classifier and inspect its errors.

You will build a text classifier, measure it honestly, and dig into the examples it misclassifies to understand why.
