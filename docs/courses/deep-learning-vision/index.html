Deep Learning & Vision

Go from tensors and autograd to convolutional networks. Build a neural network by hand first, then train and debug real image models in PyTorch.

  • PyTorch
  • Neural networks
  • CNNs
  • Computer vision
See the syllabus

What you'll learn

  1. Tensors, autograd and training loops

    Learn the PyTorch building blocks and write a training loop you understand line by line.

  2. Neural networks from scratch

    Build layers, activations and backpropagation by hand, so nothing is a black box.

  3. Convolutional models for images

    See how convolutions pick out edges and shapes, and build a CNN that classifies images.

  4. Transfer learning and model debugging

    Reuse pretrained models and diagnose the bugs that make training fail.

Your project

Train an image classifier with PyTorch.

You will train, evaluate and debug an image classifier in PyTorch, then improve it with transfer learning.
