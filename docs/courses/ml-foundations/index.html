ML Foundations

Start from zero and learn how machine learning really works: how data becomes features, how a model learns with gradient descent, and how to tell whether it is any good.

  • Python
  • NumPy
  • Scikit-learn
  • Regression
See the syllabus

What you'll learn

  1. Data, features and train/test splits

    Turn raw data into features, split it honestly, and avoid fooling yourself with leaked information.

  2. Regression and gradient descent

    Fit lines and curves, define a loss, and watch gradient descent minimize it step by step.

  3. Classification, trees and evaluation

    Predict categories, read a confusion matrix, and choose metrics that match the problem.

  4. Model selection and practical pitfalls

    Spot overfitting, use validation data, and pick a model you can defend.

Your project

Predict a real-world outcome and explain the model.

You will take a real dataset from raw table to trained model, then explain which features drive the predictions and where the model goes wrong.
