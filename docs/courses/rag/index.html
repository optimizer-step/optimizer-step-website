Build with RAG

Build retrieval-augmented generation the careful way: prepare documents, retrieve the right chunks, generate grounded answers with citations, and measure where the system fails.

  • RAG
  • Vector search
  • LLMs
  • Evaluation
See the syllabus

What you'll learn

  1. Chunking and document preparation

    Extract text from real documents and split it into chunks that retrieve well.

  2. Retrieval and vector similarity

    Embed chunks, search a vector store, and tune retrieval quality.

  3. Grounded generation and citations

    Prompt a language model to answer only from retrieved sources, with citations.

  4. Evaluate answers and failure cases

    Measure answer quality and find the failure cases before your users do.

Your project

Create a grounded question-answering workflow.

You will build a question-answering system over your own documents that cites its sources, then evaluate where it breaks.
