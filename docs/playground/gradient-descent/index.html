How gradient descent works

The model is a polynomial: a curve described by a few weights. Training means finding the weights that make the curve pass as close as possible to your points.

1. Measure the error

For every point the model makes a prediction, and we measure how far off it is. Squaring those errors and averaging them gives the mean squared error: the loss shown in the panel.

2. Step downhill

The gradient says how the loss changes when each weight moves a little. Gradient descent moves every weight a small step against it: w = w − learning_rate × gradient. Repeat, and the loss falls.

3. Pick the learning rate carefully

Too small and training crawls. Too large and every step overshoots the minimum, so the loss explodes. Try the Exploding preset, then lower the rate.

4. Match the model to the data

A degree-1 model can only draw a straight line. Higher degrees can bend, but they can also start chasing noise. That trade-off is where overfitting begins.
